# 播客粗剪人工判断表

> 先判断「整段删/整段留」，再写入 `cuts.tsv`。不要为了压时长拆散笑声、情绪尾巴或完整故事。

## 剪辑原则

- 笑声、调侃和情绪尾巴：优先保留；若必须删除，删除完整情绪段。
- 完整故事：只做整段保留或整段删除。
- 上下文承接：剪前一句和剪后一句必须能自然接上。
- 文本连贯：剪后文本必须能独立阅读通顺，不能只靠听过原素材的人脑补。
- 后文回指：若后文有「刚刚说到/所以/这个问题」等回指，前文铺垫不能删光。
- 人物转折链：包含「触发事件 -> 内心判断 -> 行动选择 -> 后续方向」时，不能按履历细节整段删除。
- 情感段、人物关系、真诚判断、关键停顿：优先保留。
- 低信息重复、录音设置、现场重启、后台交代、跑题过远：优先删除。

## 文本连贯硬检查

| 检查项 | 判断 |
|---|---|
| 剪后文本能否独立阅读通顺 | 是/否 |
| 后文是否有「刚刚说到/所以/这个问题」等回指 | 是/否 |
| 删除段是否承担人物转折链 | 是/否 |
| 删除段是否只是名单、数字、口误、后台交代或低信息重复 | 是/否 |
| `可选压缩` 是否被误当成整段删除 | 是/否 |

## 输出设置

| 项目 | 建议值 | 说明 |
|---|---|---|
| 切口缓冲 | 1 秒 | 每段删除范围按 `start+1` 到 `end-1` 执行 |
| 是否需要波形标记 | 是/否 | 需要在后期软件里修复切口时选「是」 |
| 标记方式 | 静音缺口 | 后期定位优先使用 2 秒静音缺口，波形最明显 |
| 是否启用 321 重启识别 | 是/否 | 录制中用 321 重来时选「是」，只剪能匹配上的前置重复文本 |
| 标记用途 | 定位切口 | 静音缺口版会改变总时长，不作为最终发布音频 |

## 写入 cuts.tsv 前检查

- 这一段是不是「确定删除」？
- 删除后是否破坏笑声、沉默、哽咽、调侃或情绪转场？
- 删除后是否让一个故事只剩前半段或后半段？
- 删除后上一句和下一句是否能接得上？
- 删除后后文是否还会引用已被删掉的事实、概念、故事或比喻？
- 这段是否承担「触发事件 -> 内心判断 -> 行动选择 -> 后续方向」的人物转折链？
- 如果这段只是 `可选压缩`，是否只做局部剪枝而非整段删除？
- 是否需要扩大删除范围，或改成整段保留？
- 是否需要输出 `--splice-marker-mode silence-insert --splice-silence-duration 2` 静音缺口版本，方便后期手工修复？
- 如果出现 321 重启标记，自动剪辑段是否真的只覆盖了 321 前面的重复旧 take？找不到重复文本时不要剪。
